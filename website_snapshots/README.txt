COPIA VERSIONADA DE VISTAS PÚBLICAS - 31/10/2026
Exportación de lectura de las vistas de inicio y planes publicadas en Odoo.
Los XML conservan el código QWeb y las variantes de idioma existentes.
metadata.json identifica las vistas y la fecha de captura.

No son un módulo instalable ni una migración. No importarlos automáticamente.
La página de inicio hereda una vista existente; sus IDs dependen de esa base.
Estas copias contienen únicamente código de las dos vistas públicas, sin datos
operativos, certificados ni credenciales. No incluyen todo el sistema Odoo.
No hay despliegue automático desde GitHub. La futura instalación reproducible
de la web requiere empaquetado y pruebas independientes.
